# Transcript Studio M6.14

## Scope

Single-instance startup and Windows system-tray lifecycle, based on M6.13.

## Changes

- Added per-user Mutex + named-pipe activation.
- Added notification-area icon and custom WPF tray menu.
- Added tray double-click restoration and `打开` / `退出` menu commands.
- Added minimize-to-tray behavior without disposing WebView2 or reloading the React application.
- Added disposal of tray icon and local media request handler when the main window closes.

## Preserved

- Existing React UI, subtitle parsing/editing, pagination, playback, project persistence, plain-text export and Remotion rendering behavior.
- Existing project/work-folder storage layout.
- Existing M6.13 rule that prevents closing the window while export is active (will be replaced in M6.15).

## Validation

- Source-level regression tests added for the single-instance/tray wiring and lifecycle contract.
- Portable JavaScript/TypeScript core tests are run before packaging.
- WPF/.NET compilation and interactive tray acceptance require Windows with the .NET 10 Windows Desktop SDK and are not verified in this environment.


## M6.14.1 source corrections

- Added the missing `System.IO` import to `SingleInstanceManager`.
- Qualified WPF media/control/input types in `TrayIconManager` to avoid ambiguity introduced by the Windows Forms global usings.
- Qualified both WPF `MessageBox` calls in `ReaderWindow`.
- These changes directly address the C# compiler diagnostics reported during the first Windows publish attempt.

The corrected source has been inspected and the ZIP archive is integrity-checked. This environment does not contain the .NET SDK, so a successful Windows `dotnet publish` is not claimed. The frontend dependencies are also not installed in the uploaded source package; run `npm ci` before `npm run verify`.


## M6.14.2 — WPF-only tray

- Replaced WinForms `NotifyIcon` with native Windows Shell `Shell_NotifyIcon` P/Invoke.
- Routed tray mouse notifications through the WPF main window's `HwndSource`.
- Removed the `UseWindowsForms` project property.
- Kept the context menu entirely in WPF.
- No Windows Forms or System.Drawing references remain in the desktop source/project.
