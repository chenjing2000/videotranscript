# M2 静态分页排版规范

## 页面计算

逻辑输出固定 `W=1200, H=1600`。视频宽度为 1200，高度按源视频宽高比计算，字幕视口 `Hr=1600-videoHeight`。实际字幕内容可用高度 `Ha=Hr-2*paddingY`，可用行宽 `Wa=1200-2*paddingX`。所有字号、段距、内边距均是逻辑像素，与桌面窗口缩放无关。

用字体、字重和字号绑定的 Canvas `measureText` 函数测量每个显示词与空格。段首 x 偏移为 `firstLineIndentCh * measure('0')`；普通续行 x=0。行高为 `fontSize * lineHeight`，行间词距由测得的空格宽度形成。换行时不允许拆开单词。多个自然段共处一页时，在新自然段之前增加 `paragraphGap`；新页页首段不额外增加上方段距。文本底部必须位于 `Hr-paddingY` 上方。

以全局自然行流作为输入执行动态规划分页：在保证每一页行高不超出可用高度的前提下，对页末自然段边界给予最低惩罚，句末次之，普通行末最重；同时对大面积留白施加成本。如此避免强制“每段一页”造成浪费，但允许过长段落跨页。页面中每行保存 `startWord/endWord/top/height/words[{index,id,x,width}]`，共同组成可序列化 `PagePlan`。实际使用中出现单词超过行宽的 warning，应在提高容错能力前选用更小字号或更宽的边距设置。

## 时间计算

每页有第一个可见词 `firstStart` 与最后一个可见词 `lastEnd`。第一页从 t=0 显示。

后续页的切换时刻：

- 如果 `next.firstStart > previous.lastEnd`，取两者中点。
- 否则取下一页首词开始时刻，并记录可能出现跨页语音重叠的警告。
- 若 WhisperX 时戳倒序造成切页时间倒退，钳位到上一个切页时间并报告警告。

使用二分查询 `pageAtTime(plan,t)`，无需 CSS 动画，也无需依据播放前历史状态。暂停、拖动时间轴、倒放后的显示可确定。

## 显示与导出一致性

预览负责计算一次排版计划，WPF 接收 `pagePlan` 快照，Node Remotion 原样接收且共同使用 `ReaderCanvas`。每个词绝对定位在预先计算的 x/y 位置。字体绘制所需字体及字重必须在两端可用。生产构建与 MP4 的像素一致性仍须通过 Windows 端关键帧截图验证。

## 参数预设

英文字体：Arial、Nunito Sans、Calibri、Georgia。

字号（px）：32、36、40、44、48、52；粗细：400、500、600、700。

行距倍数：1.2、1.3、1.4、1.5、1.6、1.8；段距（px）：0、12、20、28、36、48；首行缩进（ch）：0、2、4、6、8（默认 4）。

上下内边距（px）：16、24、32、40、48；左右内边距（px）：24、36、48、60、72、96。

排版项均为两列标签/控件同行，标签列 112px、间隔 12px、下拉宽 200px。最多同时显示 4 个各 36px 高的条目；额外条目在弹出层内部滚动。颜色项同列对齐，使用颜色选择器。
