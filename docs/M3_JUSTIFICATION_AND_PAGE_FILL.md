# M3 · Word 两端对齐与减少分页留白

## 范围

在已经通过 Windows PoC 的 WPF + WebView2 + React + Remotion 基础上进行**增量改动**；不修改 WPF 视频播放、Remotion 音视频合成、WhisperX 原始时间戳和逐词高亮时间函数。

## Word 式两端对齐

- 新增 `ReadingStyle.textAlign: "justify" | "left"`，默认 `justify`，旧工程通过 `migrateProjectStyle` 补齐默认值。
- 完整自然段的**非最后一行**通过增加**词与词之间的空白**，使最右侧单词的右边缘落在右内边距处。不要调整单词字形宽度。
- **自然段最后一行左对齐**；即使这一行恰好也是页面最后一行，也不拉伸。
- **跨页不是段落结束**：前页最后一行如果仍属于同一自然段，就继续两端对齐；新页续段不重复首行缩进。
- 首行缩进仍然是 `firstLineIndentCh * measure('0')`，默认 `4ch`；首行可用宽度扣除缩进，首词左边从缩进位置起，最后一词仍贴右边界。
- 少于两个单词的行不拉伸；异常超宽词保持警告，不能产生负词距。
- 每个词的 `x`、`width` 明确写入 `PagePlan`，WebView2 和 Remotion 都只消费相同的词位置。逐词高亮仍使用各自原始 `start/end`。

## 自动分页

- 调整 `pagination.ts` 中的动态规划评分：充分利用字幕区高度作为重要目标，段落末/句末为**软偏好**，不再为了让下一段完整出现在新页而留下大块空白。
- 允许自然段及句子在**完整排版行边界**跨页，绝不拆分单词；页边界不会更改 `paragraphEnd`。
- 对跨页的单行孤行/寡行给予软惩罚，但在空间不足或其它约束下允许拆页。
- 末页允许留白，不强制拉伸页高；每页顶部对齐、页内静止、切页瞬时发生。
- `PagePlan` 的翻页时间与此前的逐词高亮逻辑不变。

## UI

- 「样式 → 页面排版」增加「段落对齐」下拉框，选项「两端对齐」「左对齐」，默认两端对齐。
- 标签、下拉框共用现有两列网格，列宽及最大 4 行弹出高度保持不变。
